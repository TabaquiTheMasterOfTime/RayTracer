A simple raytracer in kotlin.

Features:
- dynamic lights
- dynamic shadows
- texturing
- fog
- multithread rendering

Controls:
- move: wasd + space + c
- rotate camera: arrows
- toggle things: F1-F5
- add a light source: enter
- exit: escape

The purpose of the project is still unclear to me, but it was kind of fun.
